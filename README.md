# Application 10 - Student Chatbot

## Aim

To create a simple chatbot for students using JavaScript.

## Description

This application provides simple responses to common student questions.

## Features

- Greeting messages
- Study guidance
- Exam guidance
- Python information
- Java information
- College-related responses
- Goodbye message

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. Student enters a message.
2. JavaScript checks the keywords.
3. The chatbot selects a suitable response.
4. The response is displayed in the chat box.

## Example

Student:
Hello

Bot:
Hello! How can I help you?

Student:
Tell me about Python

Bot:
Python is a beginner-friendly programming language.

## Application

This project demonstrates the basic concept of a rule-based chatbot and Natural Language Processing.
